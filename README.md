# LeetCode Solutions

My solutions to LeetCode problems, solved in Python, Java.

## Naming Convention

Each file is named `_NNNN_Problem_Name.py`, where `NNNN` is the zero-padded LeetCode problem number.

Example: `_0001_two_sum.py`

# Algorithms
The file also contains an folder named Algorithms where basic code for various algorithm is saved
